# Simple ATM Management System
```
C++ ATM Management System project for Linux
```

## Features
```
1) Account login with PIN
2) Check balance
3) Withdraw
4) Deposit
5) Transfer
6) Mini statement
7) Change PIN
8) Simple text-file persistence
9) Transaction logging
```

## Compile
```bash
g++ main.cpp -o atm
./atm
```
